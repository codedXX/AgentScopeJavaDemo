## 问题

### 什么时候会用MCP

~~~
启动（不连接）
  ↓
用户提问 → 意图不是 CHAT/DATA
  ↓
mcp.getObject()  ← 此刻才执行这个 @Bean 方法：连接 + 握手（≤15s）
  ↓
registerMcpClient(...)  ← 把远程工具注册进本会话 Toolkit
  ↓
ReActAgent 循环 → 模型决定调 listRepositoryFiles / readRepositoryFile 等
  ↓
容器关闭 → destroyMethod 调 close()
~~~



### public McpClientWrapper mcpClient(DemoProperties p)配置是干嘛的

这是一个 **Spring Bean 工厂方法**，负责产出一个**进程级共享、已完成握手的 MCP 客户端**。MCP（Model Context Protocol）客户端 = 你这边作为「工具消费方」，去连一个远程 MCP 服务（application.yml 里配的 `http://127.0.0.1:8086/mcp`），把对方暴露的工具拉过来给 Agent 用。
